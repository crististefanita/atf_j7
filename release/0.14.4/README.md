## Îmbunătățiri

- Partida cu AI are un singur meniu de opțiuni, bifa de joc automat în antet
  și poziția indicată în istoricul de sub tablă.

  limba aleasă la redeschidere.

  Explică păstrează tabla fixă, detaliile derulabile și comenzile la vedere.
