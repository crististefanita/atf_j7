# Chess Lab 0.16.1

## Overview

Web and Android share the same header and navigation policy.

## Improvements

- Back sits beside the title across chapters, setup, lists, openings and replay.
- Contextual menus remain at the right; puzzle options open beside their button.
- Move navigation stays centered, and compact AI control retains its accessible name.
- Open replay restores its variant and cursor after rotation.

## Installation

[Release on GitHub](https://github.com/crististefanita/chess/releases/tag/v0.16.1)

The project identity changed after 0.16.0. This edition requires a clean installation; Android cannot upgrade the earlier signed application or migrate its local saves automatically.
