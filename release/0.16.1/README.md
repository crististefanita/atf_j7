# Chess Lab 0.16.1

## Pe scurt

Web și Android folosesc aceeași politică pentru antete și navigare.

## Îmbunătățiri

- Înapoi stă lângă titlu la capitole, configurare, liste, deschideri și reluare.
- Meniurile contextuale rămân în dreapta; opțiunile problemei se deschid lângă buton.
- Navigarea mutărilor rămâne centrată, iar comanda AI compactă păstrează numele accesibil.
- Reluarea deschisă restaurează varianta și cursorul după rotație.
