# Dovezile ediției 0.12.0

După calificarea ediției, păstrați aici doar dovezile finale care identifică sursa, APK-ul semnat, verificarea Android și publicarea pornită din README-ul principal. Rapoartele sanity ale APK-ului nesemnat rămân în TMP și nu se prezintă drept calificare de distribuție.

Raportul JVM conține suita de componente, guvernanță și benchmarkul de transfer Hard. Raportul Android leagă recepțiile pentru joc și progres de restartul real al procesului. Receipt-ul de semnare compară certificatul 0.11.2 cu noua identitate și declară `CLEAN_INSTALL_REQUIRED`; calificarea, RAG-ul, metadatele GitHub și descărcarea autentificată completează proveniența.

Capturile rămân în raportul Extent lângă aserțiunea pe care o susțin; nu sunt păstrate copii de capturi sau loguri fără valoare de audit.
