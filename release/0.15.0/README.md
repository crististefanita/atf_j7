# Chess Lab 0.15.0

## Îmbunătățiri

- Pe tabla de analiză, becul oferă mutări din deschideri cât timp poziția
  are o continuare documentată. Eticheta **Teorie** arată sursa și
  deschide explicația mutării.
- Mutările de teorie pot reapărea după o transpoziție sau la revenirea în
  istoric. Motorul preia indiciul când poziția nu are continuări documentate.
- Catalogul de studiu are 14 lecții RO/EN. Cele patru adăugiri acoperă Engleza
  cu patru cai, Catalana deschisă, Nimzo-indiana Keres și Siciliana Alapin.
