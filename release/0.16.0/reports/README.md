# Dovezile ediției 0.16.0

## Pe scurt

Calificarea leagă commitul sursă, APK-ul semnat, suita de componente și observațiile Android de aceeași ediție.

- Rezultatele componentelor și aserțiunile sunt înregistrate în Extent.
- Rapoartele native includ acțiunile observate, comparațiile și capturile integrate.
- Guvernanța consemnează baza Git declarată, acoperirea înlocuitoare și continuitatea semnăturii.
- Publicarea consemnează descărcarea completă din README-ul principal.
