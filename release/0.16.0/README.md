# Chess Lab 0.16.0

## Overview

Download the signed APK from **Assets**.

## Improvements

- Calculated hints open fullscreen, with a fixed board and controls and a separately scrollable explanation.
- Hint recommendations and replay share exchange continuations within one configured search budget.
- Each available line retains its own replay step. Returning restores the displayed game position.
- Web menus stay beside their trigger on compact and large windows, with keyboard dismissal and focus return.
- The home and AI game controls follow the Android action inventory.
- Hard uses a configurable adaptive search allowance for normal game decisions.
