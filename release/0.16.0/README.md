# Chess Lab 0.16.0

## Pe scurt

Descarcă APK-ul semnat din **Assets**.

## Îmbunătățiri

- Indiciile calculate se deschid pe tot ecranul, cu tabla și comenzile fixe și explicația derulabilă separat.
- Recomandările și redarea indiciilor folosesc aceleași continuări ale schimburilor, într-un singur buget de căutare configurat.
- Fiecare linie disponibilă își păstrează pasul propriu. Revenirea restaurează poziția afișată în partidă.
- Meniurile Web stau lângă buton pe ferestre compacte și mari, cu închidere din tastatură și revenirea focusului.
- Comenzile meniului principal și ale partidei cu AI urmează inventarul Android.
- Hard folosește un buget adaptiv de căutare configurabil pentru deciziile obișnuite din partidă.
