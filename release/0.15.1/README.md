# Chess Lab 0.15.1

## Îmbunătățiri

- Becul poate reda până la trei trasee complete de teorie, cu toate
  mutările salvate și explicațiile YAML. Două trasee pot porni din
  aceeași mutare și continua diferit.
- O mutare din afara sugestiilor afișate poate intra într-o altă deschidere.
  Lista este refăcută pentru noua poziție. Ea păstrează atâtea trasee câte
  sunt disponibile, în limita a trei, înainte de revenirea la motor.
- Extent-ul general include toate cele 58 de verificări din faza inițială
  și verifică apartenența celor cinci recepții la aceeași rulare.
