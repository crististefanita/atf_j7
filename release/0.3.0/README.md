# Chess Lab 0.3.0

- Capitolul **Mat în 3** adaugă 100 de probleme, ordonate după dificultate.
- Meniul grupează capitolele Mat în 1, 2 și 3. Jocul reia capitolul și poziția salvată, iar **Următoarea** se activează după mat.
- La Mat în 2 și 3, mutarea ta rămâne vizibilă timp de 650 ms înaintea răspunsului adversarului. Marcajul culorii urmărește fiecare mutare.
- Indiciul marchează piesa cu turcoaz. **Arată mutarea** adaugă o săgeată subțire și coordonatele.
