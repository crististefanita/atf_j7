# Chess Lab 0.14.3

## Îmbunătățiri

- Toate cele șase capitole afișează sus punctele, seria și meniul cu opțiuni
  pentru întoarcerea tablei și revenirea în meniul principal.
- Săgețile și becul sunt grupate sub tablă. Meniul se deschide fără să deplaseze
  tabla, iar revenirea în capitol păstrează progresul.
