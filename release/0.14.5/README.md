# Chess Lab 0.14.5

## Îmbunătățiri

- Indiciul din partida cu AI și de pe tabla manuală oferă până la trei linii
  navigabile, în funcție de continuările care rezistă apărării.
- Fiecare linie arată evaluarea inițială, evaluarea finală și diferența
  din perspectiva culorii care mută. Un avantaj pozițional este vizibil și
  în absența unei capturi.
- Săgețile urmăresc mutările pe o tablă fixă. Revenirea păstrează poziția
  și indiciul din istoric.
